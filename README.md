# Комплекс анализ (MATH311)

МУИС-ийн бакалаврын **MATH311 Комплекс анализ** хичээлийн 16 лекцийн цахим ном. [PreTeXt](https://pretextbook.org) форматаар бичсэн бөгөөд GitHub Pages дээр автоматаар нийтлэгдэнэ. Зохиогч: Д. Даянцолмон.

## Бүтэц

Лекц бүр (номын нэг бүлэг) дараах хэсгүүдтэй:

| Хэсэг | Файл | Тайлбар |
|---|---|---|
| Лекцийн агуулга | `source/chapters/lec-NN.ptx` | Тодорхойлолт, теорем, баталгаа, жишээ |
| Нэмэлт хэсэг | `source/chapters/extra-*.ptx` | Лекц 14: Жорданы лемм; Лекц 15: Риманы зета функц |
| AI-тай дасгал | `source/chapters/ai-NN.ptx` | Claude AI бодлогыг тухай бүр зохионо: хөнгөн (Зөв/Буруу), дунд (A/B/C/D), хүнд (батлах, жишээ байгуулах; заавар ба бодолттой) |
| Семинар | `source/chapters/sem-NN.ptx` | Заавартай бодлогууд |
| Гэрийн даалгавар | `source/chapters/hw-NN.ptx` | Бодолт нь 14 хоногийн дараа нээгдэнэ |

Хавсралтууд: төгсгөлгүй үржвэр, эллипслэг функц, Лапласын хувиргалт (`app-*.ptx`).

AI дасгалын хуудас нь `source/external/ai-practice.html`. Лекц бүрийн сэдвүүдийг `ai-NN.ptx` доторх iframe-ийн `topics=` параметрээр (таслалаар тусгаарлан) өөрчилнө. Хуудас нь Math1 хичээлийн Cloudflare Worker прокси-г ашиглана.

## Гэрийн даалгаврын бодолт нээх

`homework-schedule.json`-д гэрийн даалгавар бүрийн өгсөн өдрийг бичнэ (одоогийнх нь түр огноо). Сайт өдөр бүр 00:10-д (Улаанбаатар) дахин бүтээгдэх бөгөөд `scripts/gate_homework_solutions.py` хугацаа нь болоогүй бодолтуудыг нуудаг.

## Локал дээр бүтээх

```bash
pip install -r requirements.txt
pretext build html        # output/html/
pretext view html
```

## Эх LaTeX

`latex/lectures/` нь анхны LaTeX лекцүүд. `scripts/build_book.py` нь тэдгээрээс `lec-NN.ptx` файлуудыг нэг удаа үүсгэсэн (дахин ажиллуулбал `lec-NN.ptx`-г дарна). Цаашид `.ptx` файлуудыг шууд засна.

## Нийтлэх

Repository-ийн **Settings → Pages → Source** хэсэгт **GitHub Actions**-ийг сонгоно. `main` салбарт push хийх бүрт `.github/workflows/deploy.yml` сайтыг шинэчилнэ.
